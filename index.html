Short-form publishing tool

Create, review and publish short videos.

Vengeful Creations is a desktop workflow for preparing short-form videos and publishing them to social media accounts that the user explicitly connects and authorizes.

Review before posting

Users can inspect a rendered video and its publishing settings before a post is initiated.

Authorized account access

Connections use the official OAuth authorization flows offered by supported social platforms.

Direct publishing

Approved videos can be uploaded to connected accounts using the official platform APIs.

TikTok integration

The TikTok integration uses TikTok Login Kit and the Content Posting API. A TikTok user signs in, grants the requested permissions, reviews the available publishing options and explicitly confirms a post before the video is uploaded.

Vengeful Creations is an independent application and is not affiliated with, endorsed by, or sponsored by TikTok.
